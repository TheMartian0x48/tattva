# Tattva

High-performance server framework for Zig, built from scratch.

## Overview

A comprehensive library collection for building high-performance servers, handling every byte from the moment it enters the system to the moment it leaves.

**Cross-platform I/O layer**:
- **Linux**: io_uring
- **macOS**: kqueue

## Status

🔧 **In Design** 

## Requirements

- Zig 0.15.2 or later
- Linux or macOS

## Build

```bash
zig build
zig build test
```
